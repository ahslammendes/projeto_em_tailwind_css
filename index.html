Perguntas Frequentes

Todos os tokens de cor `forest-50` a `forest-950` e a fonte `DM Sans` foram registrados via diretiva `@theme` do Tailwind CSS v4, combinados com as superfícies em vidro fosco, bordas gradientes, ícones Iconify (`lucide`, `solar`, `ri`) e animações `reveal-on-scroll`.

O projeto aplica todas as 7 categorias exigidas: Cores, Tipografia, Dimensões, Bordas e Sombras, Flexbox, CSS Grid e Responsividade (`sm:`, `md:`, `lg:`, `xl:`), com 35 classes distintas documentadas no `README.md`.

Sim! Utilizando o Tailwind CSS v4 Play CDN e os assets locais organizados em `assets/img/` e `assets/js/`, basta abrir o `index.html` ou acessar diretamente o link publicado no GitHub Pages.
